# ⚡ StudyPulse

An all-in-one web platform designed to help students track courses & syllabi, resolve tough academic doubts step-by-step with LaTeX & syntax-highlighted solutions, and enhance study habits with focus tools.

---

## 🌟 Key Features

1. **Course & Syllabus Tracker**
   - Manage enrolled courses with custom color tags, credit counts, and target grades.
   - Interactive Syllabus checklists organized by Unit with real-time completion percentage tracking.
   - Assignment & Problem Set manager with status workflow (`Pending` -> `In Progress` -> `Submitted` -> `Graded`).

2. **AI Academic Doubt Solver**
   - Instant step-by-step problem solver across **Mathematics**, **Computer Science**, **Physics**, **Chemistry**, and **General Studies**.
   - Renders LaTeX equations (`KaTeX`), syntax-highlighted code blocks, intuition summaries, pro exam tips, and follow-up active recall questions.
   - Bookmarking, search filter, and instant flashcard/quiz generation from any solved doubt.
   - Built-in offline knowledge & reasoning engine + optional Gemini API Key integration in Settings.

3. **Focus Hub & Ambient Audio Mixer**
   - Pomodoro (25m), Short Break (5m), Long Break (15m), and Deep Work (50m) intervals.
   - Procedural Web Audio API sound synthesizer: **Rain & Thunder**, **Ocean Waves**, **Cafe Noise**, and **432Hz Alpha Brainwave Drone**.
   - Automatic study time logger linked to your courses.

4. **Flashcards & Active Recall Quizzes**
   - AI-powered flashcard deck generator from any topic in 2 seconds.
   - 3D flip study mode with Spaced Repetition (SM-2: Again, Hard, Good, Easy).
   - Interactive multiple-choice practice quizzes with real-time feedback and celebration confetti!

5. **Study Analytics & Gamified Streaks**
   - Daily study hours chart (past 7 days) and course distribution breakdown using Chart.js.
   - Daily streak tracker (`🔥 7 Days`) and milestone achievement badges.
